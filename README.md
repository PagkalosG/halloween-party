# 🦇 Το Αρχείο των Σκιών

*Κάποιες στιγμές δεν έπρεπε να καταγραφούν.*

Κι όμως, κάποιος τις φωτογράφισε. Και τώρα βρίσκονται **όλες εδώ**.

Καλώς ήρθες στο ψηφιακό άλμπουμ μιας νύχτας γεμάτης περίεργες εμφανίσεις, ύποπτα χαμόγελα, ανεξήγητα βλέμματα και ανθρώπους που είπαν «θα πιω μόνο ένα».

### 🕯️ Η πόρτα είναι ανοιχτή

**[Μπες στο Αρχείο των Σκιών](https://pagkalosg.github.io/halloween-party/)**

Προσοχή στο κατώφλι. Η ομίχλη είναι μέρος της εμπειρίας. Ο τύπος με τη μάσκα στο βάθος… δεν είμαστε σίγουροι.

---

### 📸 Τι κρύβεται μέσα;

Φωτογραφίες, βίντεο και αναμνήσεις που επιβίωσαν από το Halloween.

Μπορείς να τις χαζέψεις, να τις ανοίξεις σε μεγάλη προβολή και να προσπαθήσεις να καταλάβεις ποιος κρύβεται πίσω από κάθε μάσκα.

Οι νέες φωτογραφίες εμφανίζονται στο άλμπουμ αυτόματα, όταν προστεθούν στη συλλογή. **Δεν χρειάζεται να κάνεις καμία τελετή επίκλησης.** Προς το παρόν.

### ⚰️ Μερικοί άγραφοι κανόνες

- Αν αναγνωρίσεις κάποιον κάτω από τη μάσκα, κράτα το μυστικό.
- Αν μια φωτογραφία σε κοιτάξει πίσω, κλείσ' την αργά.
- Αν εντοπίσεις τον Nosferatu, **μην του προσφέρεις σκόρδο**. Έχουμε ήδη αρκετά παράπονα.
- Αν λείπει μια φωτογραφία, ρώτα τους οικοδεσπότες. Τα φαντάσματα δεν έχουν δικαίωμα προσθήκης αρχείων.
